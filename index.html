Project Concept

Why SafeUpload exists

Most upload forms accept a file and hope for the best. SafeUpload checks it first.

PROBLEM

Users upload files to websites without knowing whether the file meets security and upload requirements.

CONCEPT

A simple file-upload testing tool that checks uploaded files against basic security and validation rules.

OBJECTIVE

Make file-upload testing simple by detecting potentially unsafe or invalid files before they reach their destination.

What We Provide

Features & benefits

Four checks run on every upload, and every result is easy to read.

File Type Validation

Checks whether the uploaded file type is allowed.

5 MB Size Validation

Ensures uploaded files do not exceed the 5 MB limit.

Filename Sanitization

Cleans the filename to make it safer to process and store.

Pass / Reject Result

Provides the user with a clear validation result after checking the file.

Limitations, Future Scope & Conclusion

Where SafeUpload goes next

LIMITATIONS

  • Limited formats
  • 5 MB limit
  • No authentication
  • No malware scanning

FUTURE SCOPE

  • Malware scanning
  • Authentication
  • Database
  • More formats
  • Detailed reports

SafeUpload provides a simple and user-friendly way to validate uploaded files before they reach their destination. By checking file type, file size, and filenames, the system provides a clear PASS or REJECT result while establishing a foundation for more advanced file-security features in the future.
